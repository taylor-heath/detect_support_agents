Method note

  • 53,867 records read from the semicolon-delimited export, with 0 blank lines and 0 rows of inconsistent field count. No rows were excluded: every record is counted in Table 1 and Table 4, and no row could not be classified.
  • The description field is LLM Reasoning. Table 3 reads that field only; Table 2 reads the registrable domain; Table 4 combines the two.
  • One status value did not match an expected value: Scraping url, 11,001 records (20.4% of the export). It is reported in the Unknown / blank row rather than dropped. No record carried Licensed gambling.
  • 16,127 records have a blank description (29.9% of the export). They cannot satisfy the Table 3 test, which reads the description alone, and so can only reach Table 4 through the domain axis.
  • The manifest reports 53,873 rows against the 53,867 records parsed here. The difference is one record whose quoted description contains six line breaks: a line count reads it as seven rows, a CSV parse as one. The parsed figure is the one used throughout.
Settings applied. All defaults from the prompt were used and none were varied: the Table 4 overall figure is the union of the .th and Thai-indicator tests, not their intersection; no TLD was excluded, so .go.th, .ac.th and .mi.th are counted and broken out beneath Table 2; and the unit of count is one record per row, not one row per registrable domain. Changing any of these changes the figures above, so they are stated rather than assumed.
