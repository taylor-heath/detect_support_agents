Method note

  • 30,151 records read from the semicolon-delimited export; 0 blank lines and 0 rows with an inconsistent field count. No rows were excluded — every record in the file is counted in Table 1 and Table 4.
  • 4,544 records have a blank description (15.1% of the export) and 9,405 more carry a description saying the page could not be read — chiefly page could not be read (7,490 records). Neither group can carry content evidence, which leaves 16,202 usable descriptions, the second denominator in Table 3.
  • The description field is LLM Reasoning. Tests A, B and C read the domain, the hostname and that field respectively; axis D reads Source. No other field was treated as a description.
  • Every status value matched an expected value. The export carries only Illegal gambling, Review needed, Not gambling and Unreachable; no Licensed gambling record appears, and no row fell into Unknown / blank. No row was left unclassified.
  • Weak-only spillover: 1,436 records carry Spanish gambling vocabulary with no STRONG indicator — 4.8% of the export, and roughly 3× the qualifying population. Counting Spanish as a Chile signal would pull all of them in and fill the picture with Peruvian, Argentine, Mexican, Colombian and Spanish estates; that is the regional contamination risk this tiering exists to hold back.

Data issues found

  • 4,544 blank descriptions, concentrated in Illegal gambling (4,042), Unreachable (499), Not gambling (3). Records with no description can qualify on a domain or Source axis, never on axis C.
  • 9,405 unreadable-page descriptions, by kind: Page could not be read 7,490, HTTP 4xx / 5xx 3,985, CDN / bot block 2,295, Parked or for-sale page 1,780, Timeout 235. A record can carry more than one kind.
  • 13 .gob.cl and 0 .gov.cl records sit inside the .cl subset. They are state domains and are reported separately beneath Table 2 so they do not distort the .cl picture silently.
  • No unrecognised status values, and no record missing both a Domain and a URL, so no row needed a Unknown / blank line or an unclassified listing.
Settings applied. All defaults from the prompt were used and none were varied: Table 4 "overall" is the union of the four axes; .gob.cl and .gov.cl are counted and reported separately; weak indicators never qualify a record alone; the Source axis is included as axis D; and the unit of count is one record per row, not one row per registrable domain. Changing any of these changes the figures above, so they are stated rather than assumed.
